
# Cynbit Smart Project Inquiry System

An enhanced project inquiry website built to improve the project enquiry experience.

## Features
- Responsive website design
- Project type and industry selection
- Project description
- Budget and timeline selection
- Contact information form
- Frontend and backend email validation
- MongoDB database integration
- Inquiry submission confirmation
- Error handling

## Technologies Used
- React.js
- JavaScript
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- CSS

## Project Structure
- client: React frontend
- server: Express backend

## Installation

### 1. Clone the repository
git clone https://github.com/palak-jain123/cynbit-smart-inquiry-system.git

### 2. Install frontend dependencies
cd client
npm install

### 3. Install backend dependencies
cd ../server
npm install

### 4. Configure environment variables

Create a .env file inside server:

MONGODB_URI=your_mongodb_connection_string

### 5. Run the backend
node server.js

### 6. Run the frontend
Open another terminal:

cd client
npm run dev

## Note
This project is an independent enhancement prototype inspired by the Cynbit Contact page.
